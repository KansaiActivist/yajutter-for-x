# ヤジュッター for X

`https://yajutter.yajuvideo.st/` の見た目・挙動を X(旧Twitter)のタイムラインに寄せる
Chrome拡張機能(Manifest V3)です。

## 機能
- ダークテーマ(X風の黒背景・配色・フォント)を適用
- タイムラインをXのような中央寄せ1カラムレイアウトに
- 投稿を「カード」化し、ホバーで背景がハイライトされるように
- 返信/リポスト/いいねに相当する数値の前にX風アイコンを表示
- 無限スクロール(スクロールで自動的に次のページを読み込み、
  元のページネーションリンクは非表示化)
- 画面右下にX風の「トップへ戻る」ボタン
- ポップアップからON/OFF切り替え可能(切り替え後は要リロード)

## インストール方法(開発者モード)
事前的にCodeからZipファイルをダウンロードし、解凍してください。
1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ(`yajutter-x-extension`)を選択
5. `https://yajutter.yajuvideo.st/` を開く(または再読み込みする)


## ファイル構成
```
yajutter-x-extension/
├── manifest.json   拡張機能の定義(Manifest V3)
├── content.css     X風ダークテーマ・レイアウト
├── content.js      投稿カード化・無限スクロール・トップへ戻るボタン
├── popup.html      拡張機能アイコンをクリックした際のポップアップ
├── popup.js        ポップアップのON/OFF切り替えロジック
├── icons/          オリジナルデザインのアイコン(既存ロゴの模倣なし)
└── README.md       このファイル
```

## 変更点
- ヘッダー(ロゴ・ログイン状態・サービス一覧・その他リンク)を、色や高さではなく中身(「サービス一覧」等の見出しとロゴ)から検出し、全ページで画面最上部の横長バーにするよう変更
- バー内部は入れ子を平らにして横一列に並べ、はみ出す分は横スクロールに(形が崩れない)
- 画面遷移やDOMの再描画でクラスが消えても再検出して復元
- 白背景のまま残る要素(話題のユーザー、通知、メッセージ、設定など)を全ページで自動的に黒背景・白文字へ変換する汎用処理を追加
- リンクの文字色が黒固定になっていた問題を修正
- 原因調査用に、ヘッダー検出時にコンソールへ `[yajutter-for-x] header bar:` を出力
